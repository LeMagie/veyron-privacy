# Veyron Privacy Website

Static privacy-policy website prepared for GitHub Pages.

## Files
- `index.html` — English privacy policy
- `style.css` — responsive dark theme
- `script.js` — table-of-contents active-section highlight

## Before publishing
1. Replace `[INSERT YOUR FULL LEGAL NAME]` in `index.html` with the operator's legal name.
2. Check the technical-log retention paragraph against the actual bot host and logging configuration.
3. Verify the consent database has a deletion schedule before claiming that withdrawn consent records are automatically deleted.
4. Confirm the actual Discord channel visibility and what exact message content the bot posts.
5. Review the legal basis, xAI contractual terms, and international-transfer safeguards for the real deployment.

## Publish with GitHub Pages
1. Create a public GitHub repository, for example `veyron-privacy`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the website. The URL will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/veyron-privacy/`

GitHub Pages may take several minutes to publish changes.
