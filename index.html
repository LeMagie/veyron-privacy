Information processed

Consent records

Veyron records your Discord user ID, your current consent status, the date and time of the recorded decision, and the policy version associated with it. These records are used to check whether AI processing is permitted. The current system keeps the latest consent state for each user; it is not a complete, immutable history of every past consent action.

Discord account-age verification

When a member uses the Veyron verification activity, Veyron reads the Discord account creation timestamp made available by Discord and calculates the account's age. Accounts younger than 5 days cannot complete verification; accounts that are at least 5 days old can pass this age check. This is a limited security measure, not proof that an account is malicious or safe. The check does not ask for a date of birth, identity document, email address, or IP address. Veyron uses the timestamp to perform the check and does not intentionally retain it as a separate user profile field.

Technical information

Moderation and strike records

When a server administrator enables a relevant moderation module, Veyron may record the Discord user ID of a person involved in a detected infraction, the date and time of the infraction, the number of strikes associated with that person, and the type of infraction (for example, an insult or another configured rule violation). These records are used to track warnings and repeated behaviour and to apply the server's moderation settings. Veyron does not need to retain the full message content as part of a strike record unless a specific moderation feature requires it.

The server administrator selects an information channel when enabling the module. Veyron may publish a notice in that channel and include a reminder in welcome messages for new members. These notices explain the processing; they are not a consent request. The fact that a member joins the server or receives the notice does not constitute consent.

Depending on how a server configures and uses moderation, the server administrator and the Veyron operator may have separate or shared data-protection responsibilities. The administrator determines whether to enable the feature and the server-specific moderation rules. The Veyron operator is responsible for the bot service and its own processing. Their exact roles depend on the purposes and means each actually determines.

Moderation and strike records are retained only for the period configured for the relevant server and only for as long as needed for moderation and abuse prevention. The server administrator must choose an appropriate period and communicate it to members. The bot must enforce automatic deletion at the end of that period; a period that has not been configured or implemented must not be represented as an active deletion guarantee.

SECURITY / AUTOMATED MODERATION

Automated security moderation

To help protect Discord servers against abuse, Veyron may automatically analyse messages for suspicious activity, including spam, repeated messages, excessive mentions, suspicious links, insults, and configured prohibited words. This processing takes place only when the relevant server administrator enables the moderation module and is intended for server security and abuse prevention.

For modules that use warnings or strikes, Veyron may store the affected user's Discord ID, the date and time of each infraction, the strike count, and the infraction type. These records allow the bot to track repeated behaviour and apply the server's configured moderation rules. The bot's information notice is published in the channel selected by the administrator and may also be referenced in welcome messages for new members.

Server administrators are responsible for selecting an appropriate retention period for their server and ensuring members are informed. Veyron should automatically delete strike records when that period expires. A server's activation of the module does not make its members' joining or silence an acceptance of these Terms or a consent to processing.

Depending on the severity assigned by the system, Veyron may take the following actions:

  • Normal: no moderation action is taken.
  • Review: a notification may be sent to server moderators so they can review the activity.
  • High: the message may be deleted and moderators alerted. This level does not by itself trigger a timeout or a kick.
  • Critical: the message may be deleted and the member may receive a one-hour timeout. If a new Critical-level offence is detected for that member within the following 3 days, Veyron may kick the member from that server. Veyron does not automatically ban members.

These automated measures are security safeguards and may occasionally make mistakes. Server moderators remain able to review the situation and apply their own moderation decisions. The account-age verification check described above is a separate security signal and is not, by itself, proof of malicious behaviour.
